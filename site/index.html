Hold a key, talk, let go. 按住快捷键，说话，松开。

Yap is dictation for macOS. Talk in English, Chinese or both in one sentence; when you let go, clean text is pasted into whatever app you're in.

Yap 是 macOS 上的听写工具。中英混着说也行；一松开，整理好的文字就粘贴进你正在用的 app。

Install with Homebrew用 Homebrew 安装 Download the latest release下载最新版本

Install安装

macOS 15 or later. Homebrew installs Yap and keeps it updated; the app also updates itself.

需要 macOS 15 或更高版本。Homebrew 负责安装和更新；app 自己也会检查更新。

brew tap sma1lboy/yap https://github.com/Sma1lboy/yap brew install --cask sma1lboy/yap/yap

Or download Yap.zip from the latest release. Builds are signed with a stable self-signed certificate but not notarized; Homebrew clears the quarantine flag for you.

也可以从最新版本下载 Yap.zip。每个版本都用同一张自签名证书签名，但没有经过 Apple 公证；用 Homebrew 安装会自动去掉隔离标记。

Two ways to run it两种用法

Both use the same models: MAI-Transcribe-2 for speech, DeepSeek V4.1 Flash to clean it up. Pick one during setup and switch any time.

两种方式用的是同一套模型：MAI-Transcribe-2 负责转写，DeepSeek V4.1 Flash 负责整理。首次设置时选一种，之后随时可以换。

Yap Cloud

No API keys. Pay for what you use.不用 API key，用多少付多少。

$1 free credit for new accounts新账户赠送额度
  • Sign in with your email and a 6-digit code.
  • Each request costs the model's price plus 10%.
  • Top up $5, $10, $20 or any amount up to $500.
  • Set a monthly spending cap; at the cap, charges stop until next month.
  • See this month's spend and which Macs are signed in.
  • 用邮箱和 6 位验证码登录。
  • 每次请求按模型价格加 10% 计费。
  • 充值 $5、$10、$20，或最多 $500 的任意金额。
  • 可以设置每月消费上限，达到后当月不再扣费。
  • 能看到本月花费，以及哪些 Mac 登录了账户。
Your OpenRouter Key

Bring your own key, pay OpenRouter directly.自带 key，费用直接付给 OpenRouter。

~$0.13 per hour of speech, at OpenRouter's prices每小时语音，按 OpenRouter 的价格
  • Paste an OpenRouter API key once; it stays in this Mac's keychain.
  • Audio and text go only to OpenRouter.
  • No account with Yap needed.
  • 粘贴一次 OpenRouter API key，它只保存在这台 Mac 的钥匙串里。
  • 音频和文字只发送给 OpenRouter。
  • 不需要 Yap 账户。

Prefer another provider, or nothing leaving your Mac? Yap also works with your own key for other providers, or NVIDIA's Parakeet running locally.

想用别的服务商，或者完全不出这台 Mac？也可以填其他服务商的 key，或在本机运行 NVIDIA 的 Parakeet 模型。

The same setup on every Mac每台 Mac 同一套设置

Your modes, prompts, dictionary and shortcuts live in one file, ~/.config/yap/config.json. Turn on Sync via Yap Cloud and every Mac signed in to your account keeps it the same.

你的模式、提示词、词典和快捷键都在一个文件里：~/.config/yap/config.json。打开「通过 Yap Cloud 同步」，登录同一账户的每台 Mac 都保持一致。

Edit anywhere哪里改都行

Change a setting in the app or in the file. Edits from different Macs are merged, and what you delete stays deleted.

在 app 里改或直接改文件都可以。不同 Mac 的改动会自动合并，删掉的不会再回来。

New Mac in one step新 Mac 一步恢复

The first setup screen can sign in and restore everything from your other Mac.

首次设置的第一屏就能登录，把另一台 Mac 的设置全部恢复过来。

Version history版本历史

Earlier synced versions are listed in Settings, and you can restore any of them. API keys are never uploaded.

设置里能看到同步过的旧版本，可以恢复任意一个。API key 永远不会上传。
