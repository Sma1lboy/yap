## Other findings (not blocking)

- **Onboarding progress counter.** The ring counts the microphone step even when it's skipped, and its total changes once a preset is picked (8 at the start, 7 after choosing Yap Cloud or an OpenRouter key). So on the 6-screen path the model screen (2nd) shows "3 of 8" and the first practice screen (3rd) "4 of 7". The screen count in the notes is right; the percentage isn't exact. UI worker's area.
- **Internal docs ship in the app.** The `releases` folder resource is the whole `docs/releases` directory, so `checklist.md`, and this report once committed, are copied into `Yap.app/Contents/Resources/releases/`. Only `<version>.md` is read. Suggest bundling only the version notes, or moving checklist and reports elsewhere.
- **cloud-smoke's funded check** (real billed transcription + chat, $0.01) wasn't run; optional.

## Release blockers

1. **Sign-in emails aren't sent.** `RESEND_API_KEY` and `MAIL_FROM` are unset on paygate-yap production (checked with `railway variables`, names only). Nobody can receive a sign-in code, so Yap Cloud (the default onboarding choice), restore on a new Mac and sync are unreachable for real users.
2. **Payments aren't configured.** `STRIPE_SECRET_KEY` and `STRIPE_WEBHOOK_SECRET` are unset. After the $1 credit, Add Funds can't work, and the notes promise receipts.
3. **No database backup.** paygate's `docs/backup.md` (checked 2026-09-25): no scheduled or existing volume backups, point-in-time recovery off. The ledger (real money) lives on a single Railway volume. At least turn on Railway volume backups or PITR (`railway postgres pitr enable -s Postgres`), and preferably also run a nightly dump to storage outside Railway.
4. **Legal pages are drafts.** `/v1/info.legal.draft` = true for `/privacy` and `/terms`; the pages show "草稿，待审阅". After review, set `LEGAL_DRAFT=false` on paygate-yap (it defaults to true).
5. **No support contact.** `/v1/info.supportEmail` is null (`SUPPORT_EMAIL` unset). Users with a billing problem have nowhere to write, and the legal pages will need it too.
