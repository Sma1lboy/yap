# Yap 1.2.0

Changes since 1.1.0. 中文在下面。

## Yap Cloud

- New optional account: sign in with your email and a 6-digit code, and Yap transcribes and cleans up your dictation without any API keys. You pay per use from a prepaid balance.
- New accounts get $1 of free credit, so you can start dictating before adding funds.
- Add funds from Account ($5, $10, $20 or a custom amount up to $500). Checkout opens in your browser; the balance updates when you come back to Yap, and each top-up has a receipt link.
- Account shows your balance, what you spent this month and on which models, and how long the balance lasts at your current pace. Home and the menu bar warn when the balance runs low.
- Set a monthly spending cap ($0 to $10,000). When you reach it, Yap Cloud stops charging until next month or until you raise it.
- See the Macs signed in to your account and sign out any of them remotely.
- If Yap Cloud can't be reached, Yap says so in one sentence, shows a banner, and recovers on its own. A failed call is retried once, only when it can't have been billed.
- Running out of balance, a signed-out Mac, and other account problems now show what to do next (Add Funds, Open Account) before you start recording.

## Settings in a file, synced across Macs

- `~/.config/yap/config.json` now covers modes, prompts, dictionary, shortcuts, general settings, custom models and custom enhancement providers. Shortcuts are written in a readable form, like `"cmd+shift+space"`.
- Settings > Config & Sync can write your current settings back to the file.
- Turn on Sync via Yap Cloud to keep the same config on every Mac signed in to your account. Changes from different Macs are merged; entries you delete stay deleted. API keys are never uploaded.
- Setting up a new Mac? The first onboarding screen can sign in and restore your settings from Yap Cloud.
- Version History lists earlier synced versions of your config and can restore one.

## Faster first run

- Onboarding is 6 screens instead of 9, and your first dictation happens on the third screen.
- Yap Cloud is the default for new users; "Your OpenRouter Key" (pay OpenRouter directly) is the second option.
- A shortcut (Right Option) is set for you, and you can change it on the practice screen. Only one microphone? That screen is skipped. Onboarding continues by itself once permissions are granted, and practice steps after the first can be skipped.
- "Set It Up Later" leaves you with a working mode and shortcut instead of a hotkey that does nothing.

## Clearer errors

- A failed transcription shows why and offers Retry; the recording is kept.
- If Yap can't paste (Accessibility not allowed), the text stays on your clipboard and Yap tells you how to fix it.
- Missing microphone permission, a missing or unusable model, and a rejected API key are caught before recording starts, with a button to the right place.
- Failed model downloads, custom commands and sync show the reason and a way to retry.

## Accessibility and polish

- VoiceOver labels for icon buttons, menus and switches; History, mode and prompt lists work with the keyboard; the info (i) buttons can be opened with the keyboard.
- Better contrast in light mode, a resizable main window, Settings… (⌘,) in the app menu, and an About section with version and Check for Updates.
- A new duck icon in the menu bar that follows light and dark mode.

## Cleanup

- Removed what was left of upstream VoiceInk: licensing and trial screens, the announcements fetcher, the change log sheet, and VoiceInk names in the UI. Custom command scripts get `YAP_*` environment variables; `VOICEINK_*` still work.
- Includes the latest upstream fix for case-only word replacements.

# Yap 1.2.0（中文）

自 1.1.0 以来的更新。

## Yap Cloud

- 新增可选的账户：用邮箱和 6 位验证码登录，不需要任何 API key 就能转写和润色。按量付费，从预充值的余额里扣。
- 新账户赠送 $1 额度，充值之前就能开始听写。
- 在「账户」页充值（$5、$10、$20，或自定义金额，最高 $500）。付款在浏览器里完成，回到 Yap 余额会自动更新，每笔充值都有收据链接。
- 「账户」页显示余额、本月花费及主要模型，以及按当前用量余额还能用多久。余额不足时，首页和菜单栏会提醒。
- 可以设置每月消费上限（$0 到 $10,000）。达到上限后，Yap Cloud 当月不再扣费，直到下个月或你调高上限。
- 可以查看已登录账户的所有 Mac，并远程让其中任意一台退出登录。
- Yap Cloud 连不上时，Yap 会用一句话说明、显示横幅，并自动恢复。失败的请求只在确定没有扣费时自动重试一次。
- 余额用完、这台 Mac 已退出登录等账户问题，会在开始录音之前就提示下一步该做什么（充值、打开账户）。

## 用配置文件管理设置，并在多台 Mac 间同步

- `~/.config/yap/config.json` 现在涵盖模式、提示词、词典、快捷键、通用设置、自定义模型和自定义润色服务商。快捷键用易读的写法，例如 `"cmd+shift+space"`。
- 「设置 > 配置与同步」可以把当前设置写回配置文件。
- 打开「通过 Yap Cloud 同步」，登录同一账户的每台 Mac 都使用同一份配置。不同 Mac 上的改动会自动合并，删掉的条目不会再回来。API key 永远不会上传。
- 在新 Mac 上？引导流程的第一屏就可以登录 Yap Cloud 并恢复你的设置。
- 「版本历史」列出同步过的配置的旧版本，可以恢复其中任意一个。

## 首次使用更快

- 引导流程从 9 屏缩短到 6 屏，第一次听写在第 3 屏。
- 新用户默认选 Yap Cloud；「自带 OpenRouter Key」（费用直接付给 OpenRouter）是第二个选项。
- 快捷键默认设为右 Option，可以在练习页更改。只有一个麦克风时跳过选择麦克风那一屏。授予权限后自动进入下一步，第一个之后的练习步骤可以跳过。
- 选「稍后设置」也会有可用的模式和快捷键，不会出现按了快捷键没反应的情况。

## 错误提示更清楚

- 转写失败时说明原因并提供「重试」，录音会保留。
- 无法粘贴（没有辅助功能权限）时，文字会留在剪贴板里，并告诉你怎么解决。
- 麦克风权限缺失、模型缺失或不可用、API key 被拒绝，会在开始录音前就发现，并提供直达相应页面的按钮。
- 模型下载失败、自定义命令失败和同步失败都会说明原因，并提供重试的入口。

## 可访问性与细节

- 图标按钮、菜单和开关都有 VoiceOver 标签；历史记录、模式和提示词列表可以用键盘操作；信息（i）按钮可以用键盘打开。
- 浅色模式下对比度更好；主窗口可以调整大小；应用菜单里有「设置…」（⌘,）；设置里新增「关于」，显示版本号和「检查更新」。
- 菜单栏换成了新的小鸭子图标，会跟随浅色/深色模式。

## 清理

- 去掉了上游 VoiceInk 的残留：授权和试用界面、公告拉取、更新日志弹窗，以及界面里的 VoiceInk 名称。自定义命令脚本可以使用 `YAP_*` 环境变量，`VOICEINK_*` 仍然可用。
- 包含上游最新的修复：仅大小写不同的词语替换不再被误判为循环。
