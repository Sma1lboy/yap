# Yap 1.7.0

Changes since 1.6.1. 中文在下面。

Yap is an open-source (GPL-3.0) dictation app for macOS, forked from VoiceInk. Hold a shortcut, talk in English, Chinese or both in one sentence, and let go: Yap transcribes, cleans up, and pastes. Run it on a local model, with your own provider key, or through Yap Cloud.

## Meetings

- A stray key can no longer end a meeting. While a meeting is recording, pressing the meeting shortcut only brings the meeting panel forward and reminds you: "Still recording. Click ✓ to end the meeting."
- The panel's Stop button is now a ✓ button, "End Meeting and Save". Ending a meeting always saves it; there is no discard.
- Quitting with ⌘Q during a meeting asks first. The default button is Keep Recording, so a stray Return does not end it. "End Meeting and Quit" saves the transcript and notes, then quits.
- The tips in Settings, the recording consent note and the onboarding line now tell you to click ✓ to stop.

## Scratchpad

- New Scratchpad: a small floating note that stays on top and stays open when you click elsewhere, so you can dictate into it from any app. It remembers its position and size.
- Open it from the menu bar, or set a shortcut in Settings (no shortcut is set by default). The shortcut opens it, or closes it if it is already in front.
- When a dictation finds no text field to paste into, the text is added to the Scratchpad with the time. The notice offers an Open Scratchpad button.
- The text stays on this Mac and is included in backups.

# Yap 1.7.0（中文）

1.6.1 之后的改动。

Yap 是一个开源（GPL-3.0）的 macOS 听写 app，fork 自 VoiceInk。按住快捷键，用中文、英文或者一句话里中英混着说，松开：Yap 转写、清理，然后粘贴。可以用本机模型、你自己的服务商 key，或者 Yap Cloud。

## 会议

- 误按键不会再结束会议。会议录制中按会议快捷键，只会把会议面板带到前面，并提示“仍在录制。点 ✓ 结束会议。”
- 面板上的停止按钮换成了 ✓ 按钮，“结束会议并保存”。结束会议一定会保存，没有放弃选项。
- 会议中按 ⌘Q 会先确认。默认按钮是“继续录制”，误按回车不会结束会议。“结束会议并退出”会保存转写和笔记，然后退出。
- 设置里的提示、录制同意说明和引导文案现在都写明点 ✓ 停止。

## 记事板

- 新增记事板（Scratchpad）：一个置顶的小浮窗，点别处也不会关，可以在任何 app 里往里听写。它会记住位置和大小。
- 从菜单栏打开，或在设置里设一个快捷键（默认不设）。快捷键会打开它，已经在最前面时则关闭。
- 听写找不到可粘贴的输入框时，文字会带上时间加进记事板。提示里有“打开记事板”按钮。
- 文字只存在这台 Mac 上，并包含在备份里。
