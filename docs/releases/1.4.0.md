# Yap 1.4.0

Changes since 1.3.0. 中文在下面。

Yap is an open-source (GPL-3.0) dictation app for macOS, forked from VoiceInk. Hold a shortcut, talk in English, Chinese or both in one sentence, and let go: Yap transcribes, cleans up, and pastes. Run it on a local model, with your own provider key, or through Yap Cloud.

## History

- Each dictation records the app it went into, shown in the list rows and the info panel.
- Filter by app, mode or meetings, combined with search.
- Sort by newest, oldest, longest or most words.
- Right-click a row: copy, copy original, paste again, retranscribe, info, delete.

## Dictation

- If no text field is focused when you finish, the dictation stays on the clipboard and Yap tells you so, instead of pasting nowhere.
- Word replacements accept multi-line text, and list rows show the first line.
- New starter mode: Translate to English.
- The menu bar has a Language submenu that sets the active mode's dictation language.
- Cleanup also sees the date, time, time zone and your account name.

## Editing and rewriting

- Undo Last Paste puts back the text the paste replaced, instead of just deleting.
- Rewrite mode with nothing selected tells you to select text first, instead of pasting nothing.
- Home and the feature tour list Edit Selected Text, which uses the Rewrite mode.

## App polish

- Icons: the sidebar and the most used icons are now Phosphor, gray, with a duck-yellow selected item.
- Onboarding: the microphone step shows a live input level on the highlighted device, and the practice sentences are translated (中文, Deutsch, Français).
- Yap offers to move itself into Applications when a downloaded copy runs from another folder.
- The site and README no longer say Yap isn't notarized, and answer the permission reset after 1.3.0.

# Yap 1.4.0（中文）

1.3.0 之后的改动。

Yap 是一个开源（GPL-3.0）的 macOS 听写 app，fork 自 VoiceInk。按住快捷键，用中文、英文或者一句话里中英混着说，松开：Yap 转写、清理，然后粘贴。可以用本机模型、你自己的服务商 key，或者 Yap Cloud。

## 历史记录

- 每条听写会记下它输入到了哪个 app，列表行和详情面板里都能看到。
- 可以按 app、模式或会议筛选，并且能和搜索一起用。
- 可以按最新、最早、最长或字数最多排序。
- 右键一行：复制、复制原文、再次粘贴、重新转写、详情、删除。

## 听写

- 结束时如果没有聚焦的文本框，听写结果会留在剪贴板里，并提示你，而不是粘贴到空处。
- 词语替换支持多行文本，列表里显示第一行。
- 新增起步模式：翻译成英文。
- 菜单栏新增“语言”子菜单，用来设置当前模式的听写语言。
- 清理时还会参考日期、时间、时区和你的账户名。

## 编辑和改写

- 撤销上次粘贴会把被这次粘贴替换掉的文字放回去，而不是只删除。
- 没有选中文字时使用改写模式，会提示先选中文字，而不是粘贴一段空内容。
- 主页和功能导览新增“编辑选中文字”，它用的是改写模式。

## 界面细节

- 图标：侧边栏和最常用的图标换成了 Phosphor，灰色，选中项是鸭黄色。
- 新手引导：麦克风一步会在高亮的设备上显示实时输入电平，练习句子有中文、德语、法语翻译。
- 从其他文件夹运行下载的 Yap 时，会提示把它移到“应用程序”。
- 网站和 README 不再写“未公证”，并补上了 1.3.0 之后权限需要重新授权的说明。
