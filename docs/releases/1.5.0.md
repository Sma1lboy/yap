# Yap 1.5.0

Changes since 1.4.0. 中文在下面。

Yap is an open-source (GPL-3.0) dictation app for macOS, forked from VoiceInk. Hold a shortcut, talk in English, Chinese or both in one sentence, and let go: Yap transcribes, cleans up, and pastes. Run it on a local model, with your own provider key, or through Yap Cloud.

## Settings

- New Account section at the top of Settings. Signed out, it explains Yap Cloud and lets you sign in. Signed in, it shows your email, a switch to sync settings across Macs, sync status with Retry and Sync Now, Version History, Manage Yap Cloud, and Sign Out.
- Config & Sync is now Config File and holds only the config-file rows and VoiceInk import.
- A search field at the top of Settings filters sections by title or row name, and says when nothing matches.
- Settings › Shortcuts has Restore Default Shortcuts…, which lists each change and asks before applying. Your modes are untouched.

## Shortcuts and recording

- New Copy Last Transcription shortcut (unset by default) copies the cleaned-up text, or the original if there is none. It is included in settings backup and config.json.
- Cancelling a recording of 15 seconds or more asks first: press the cancel key again within 3 seconds to discard it. With Esc, long recordings show "Press Esc again to discard".

## When something goes wrong

- A recording that is too quiet is no longer transcribed. The notification names the input device you are using and opens Audio Settings.
- If a transcript is only one of Whisper's made-up phrases (English or Chinese), it isn't pasted. History keeps the text with a Filtered status, and Yap tells you it didn't catch anything.
- If Yap quit in the middle of a recording, the audio (up to 3 days old) is kept, and the next launch offers to transcribe it with your current mode or discard it.

# Yap 1.5.0（中文）

1.4.0 之后的改动。

Yap 是一个开源（GPL-3.0）的 macOS 听写 app，fork 自 VoiceInk。按住快捷键，用中文、英文或者一句话里中英混着说，松开：Yap 转写、清理，然后粘贴。可以用本机模型、你自己的服务商 key，或者 Yap Cloud。

## 设置

- 设置顶部新增“账户”分区。未登录时说明 Yap Cloud 并可以直接登录；登录后显示邮箱、“跨 Mac 同步设置”开关、同步状态（可重试、立即同步）、版本历史、管理 Yap Cloud 和退出登录。
- “配置与同步”改名为“配置文件”，只保留配置文件相关的行和 VoiceInk 导入。
- 设置顶部有搜索框，按分区标题或设置项名称过滤，没有匹配时会提示。
- 设置 › 快捷键 新增“恢复默认快捷键…”，会先列出每一项改动再让你确认。模式不受影响。

## 快捷键和录音

- 新增“复制上一次转写”快捷键（默认未设置），复制清理后的文字，没有的话复制原文。已包含在设置备份和 config.json 里。
- 取消 15 秒或更长的录音时会先确认：3 秒内再按一次取消键才会丢弃。用 Esc 取消时，长录音会显示“再按一次 Esc 丢弃”。

## 出问题的时候

- 太安静的录音不再转写。通知里会写出当前使用的输入设备，并可以打开音频设置。
- 如果转写结果整句都是 Whisper 编造的常见短语（中文或英文），不会粘贴。历史记录里保留文字并标为“已过滤”，Yap 会告诉你没有听到内容。
- 如果 Yap 在录音过程中退出了，3 天内的录音会保留，下次启动时可以选择用当前模式转写，或者丢弃。
