# Yap 1.6.1

Changes since 1.6.0. 中文在下面。

Yap is an open-source (GPL-3.0) dictation app for macOS, forked from VoiceInk. Hold a shortcut, talk in English, Chinese or both in one sentence, and let go: Yap transcribes, cleans up, and pastes. Run it on a local model, with your own provider key, or through Yap Cloud.

## Meetings

- The feature tour has a new Record Meeting card that shows the meeting shortcut.
- The last onboarding screen now mentions meeting recording. If you have set a meeting shortcut it shows the shortcut; otherwise it points you to Settings to set one.

## Website

- New changelog page: https://yap.sma1lboy.me/changelog.html
- New troubleshooting page: https://yap.sma1lboy.me/help.html
- The download section shows the latest version, file size and system requirements.

# Yap 1.6.1（中文）

1.6.0 之后的改动。

Yap 是一个开源（GPL-3.0）的 macOS 听写 app，fork 自 VoiceInk。按住快捷键，用中文、英文或者一句话里中英混着说，松开：Yap 转写、清理，然后粘贴。可以用本机模型、你自己的服务商 key，或者 Yap Cloud。

## 会议

- 功能导览新增“录制会议”卡片，显示会议录制的快捷键。
- 引导的最后一屏现在会介绍会议录制。如果你已经设置了会议快捷键，会显示该快捷键；没有的话，会提示你去设置里设一个。
