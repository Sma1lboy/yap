**封面大字：** 中英混着说，Mac 听写不翻车

**标题：** 写代码时的中英混说，终于有听写能接住了

**正文：**

我说话是这样的：「OAuth Refresh Token 现在存在 Local Storage 里，有 XSS 风险」。

试过的听写工具，要么只能选一种语言，要么把英文词写成发音相近的汉字，要么把半句话翻译掉。

所以我在开源听写 app VoiceInk 的基础上改了一个版本，叫 Yap，今天发 1.2.0：

1. 按住右 Option 说话，松开，文字直接粘贴进你正在用的 app（微信、飞书、VS Code、浏览器都行）。
2. 一句话里中英混着说，每一段按它自己的语言转写。
3. 可以只用这台 Mac 上的模型：下载一次 547 MB，之后断网也能用，8 GB 内存的 Mac 也跑得动。
4. 你改过的错字，它可以记进词典，下次拼对；手动模式下每一条都要你点头才生效。

测试集和分数都公开在 GitHub 上：11 段中英混说的音频、82 个英文术语和人名，推荐的云端模型对 59 个，本地模型加词典对 54 个。

免费、开源（GPL-3.0），需要 macOS 15 以上。GitHub 搜 Sma1lboy/yap，官网 yap.sma1lboy.me。
